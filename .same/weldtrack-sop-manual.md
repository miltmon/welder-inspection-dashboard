## **1. INTRODUCTION & SCOPE**

### **1.1 Purpose**
This Standard Operating Procedure (SOP) establishes standardized methods for conducting AWS D1.1 Clause 6 visual inspections using the WeldTrack™ Inspector platform. This SOP ensures consistent, compliant, and professional inspection practices across all users and projects.

### **1.2 Scope**
This SOP applies to:
- Certified Welding Inspectors (CWI) using WeldTrack™ Inspector
- Quality Control personnel conducting visual inspections
- Supervisory personnel reviewing inspection reports
- All structural welding projects requiring AWS D1.1 compliance

### **1.3 Regulatory Compliance**
- **AWS D1.1:2020** - Structural Welding Code - Steel
- **ASME Section IX** - Welding, Brazing, and Fusing Qualifications
- **ASNT SNT-TC-1A** - Personnel Qualification and Certification
- **ISO 9712** - Non-destructive testing qualification and certification

### **1.4 Definitions**
- **CWI**: Certified Welding Inspector
- **WPS**: Welding Procedure Specification
- **PQR**: Procedure Qualification Record
- **NDT**: Non-Destructive Testing
- **VT**: Visual Testing

## **4. AWS D1.1 CLAUSE 6 VISUAL INSPECTION PROCESS**

### **4.1 Systematic Inspection Sequence**
**CRITICAL: Follow this exact order for every weld inspection**

#### **4.1.1 UNDERCUT (Priority: HIGH)**
**Definition:** Groove melted into base metal at weld toe

**Inspection Procedure:**
1. Clean weld toe areas completely
2. Use adequate lighting (1000+ lux)
3. Measure depth with appropriate gauge
4. Document maximum depth observed
5. Note length of undercut areas

**Acceptance Criteria (AWS D1.1 Table 8.1):**
- ✅ **ACCEPTABLE**: Depth ≤ 1/32" (0.8mm)
- ✅ **ACCEPTABLE**: Does not reduce effective throat
- ✅ **ACCEPTABLE**: Intermittent, within length limits
- ❌ **REJECTION**: Depth > 1/32" (0.8mm)
- ❌ **REJECTION**: Reduces throat below minimum
- ❌ **REJECTION**: Continuous length > 2" (50mm)

**Documentation Requirements:**
- Record maximum depth measurement
- Note location and extent
- Photograph if exceeds limits
- Mark status: PASS/FAIL

#### **4.1.2 CRACKS (Priority: HIGH)**
**Definition:** Linear discontinuities in weld or base metal

**Inspection Procedure:**
1. Examine entire weld length systematically
2. Check crater areas carefully
3. Inspect heat-affected zones
4. Use magnification if necessary
5. Mark any suspected crack locations

**Acceptance Criteria (AWS D1.1):**
- ❌ **REJECTION**: ANY crack of any size
- ❌ **REJECTION**: Crater cracks
- ❌ **REJECTION**: Longitudinal cracks
- ❌ **REJECTION**: Transverse cracks
- ❌ **REJECTION**: Base metal cracks

**Documentation Requirements:**
- Immediate FAIL if any crack detected
- Photograph all crack locations
- Measure and record crack dimensions
- Note crack orientation and location

#### **4.1.3 POROSITY (Priority: MEDIUM)**
**Definition:** Gas pockets trapped in weld metal

**Inspection Procedure:**
1. Examine weld face under proper lighting
2. Count individual pores per linear inch
3. Measure largest pore dimensions
4. Note distribution pattern
5. Calculate total porosity per inch

**Acceptance Criteria (AWS D1.1):**
- ✅ **ACCEPTABLE**: Individual pores ≤ 3/32" (2.4mm)
- ✅ **ACCEPTABLE**: Sum ≤ 3/8" (9.5mm) per linear inch
- ✅ **ACCEPTABLE**: Scattered distribution
- ❌ **REJECTION**: Individual pore > 3/32" (2.4mm)
- ❌ **REJECTION**: Sum of pores > 3/8" (9.5mm) per linear inch
- ❌ **REJECTION**: Cluster porosity

**Documentation Requirements:**
- Count and measure pores per inch
- Record largest pore dimension
- Note distribution pattern
- Photograph if rejection criteria met

#### **4.1.4 OVERLAP (Priority: MEDIUM)**
**Definition:** Weld metal extending beyond weld toe without fusion

**Inspection Procedure:**
1. Examine weld toes carefully
2. Look for unfused overlap areas
3. Check for proper tie-in
4. Verify fusion at boundaries
5. Document any overlap conditions

**Acceptance Criteria (AWS D1.1):**
- ❌ **REJECTION**: ANY overlap is cause for rejection

**Documentation Requirements:**
- Immediate FAIL if overlap detected
- Photograph overlap areas
- Note location and extent
- Record remedial action required

#### **4.1.5 INCOMPLETE FUSION (Priority: HIGH)**
**Definition:** Lack of fusion between weld and base metal

**Inspection Procedure:**
1. Examine weld boundaries thoroughly
2. Look for visible lack of fusion
3. Check sidewall fusion
4. Verify root fusion where accessible
5. Note any questionable areas

**Acceptance Criteria (AWS D1.1):**
- ❌ **REJECTION**: ANY incomplete fusion is cause for rejection

**Documentation Requirements:**
- Immediate FAIL if detected
- Photograph fusion problems
- Note specific locations
- Document extent of problem

#### **4.1.6 ARC STRIKES (Priority: HIGH)**
**Definition:** Arc strikes outside of weld area

**Inspection Procedure:**
1. Examine entire base metal surface
2. Look for discoloration or melting
3. Check areas adjacent to welds
4. Document any arc strike locations
5. Assess impact on base metal

**Acceptance Criteria (AWS D1.1):**
- ❌ **REJECTION**: Arc strikes outside weld area not permitted

**Documentation Requirements:**
- Record all arc strike locations
- Photograph each occurrence
- Note size and depth
- Document remedial requirements

#### **4.1.7 WELD PROFILE (Priority: HIGH)**
**Definition:** Weld size, contour, and reinforcement

**Inspection Procedure:**
1. Measure weld leg sizes
2. Check weld contour
3. Verify reinforcement limits
4. Assess overall profile
5. Compare to WPS requirements

**Acceptance Criteria (AWS D1.1):**
- ✅ **ACCEPTABLE**: Meets WPS size requirements
- ✅ **ACCEPTABLE**: Smooth transition to base metal
- ✅ **ACCEPTABLE**: Reinforcement within limits
- ❌ **REJECTION**: Undersized welds
- ❌ **REJECTION**: Excessive reinforcement
- ❌ **REJECTION**: Poor contour

**Documentation Requirements:**
- Record actual weld sizes
- Note profile quality
- Compare to requirements
- Document deviations

#### **4.1.8 BASE METAL CONDITION (Priority: MEDIUM)**
**Definition:** Base metal preparation and surface condition

**Inspection Procedure:**
1. Check surface preparation quality
2. Verify edge preparation
3. Examine for base metal defects
4. Assess cleanliness
5. Document preparation compliance

**Acceptance Criteria:**
- ✅ **ACCEPTABLE**: Proper preparation per WPS
- ✅ **ACCEPTABLE**: Clean, oxide-free surfaces
- ✅ **ACCEPTABLE**: Correct edge geometry
- ❌ **REJECTION**: Improper preparation
- ❌ **REJECTION**: Contaminated surfaces
- ❌ **REJECTION**: Incorrect geometry

## **5. DOCUMENTATION & PHOTOGRAPHY STANDARDS**

### **5.1 Photography Requirements**
**MANDATORY for all FAIL conditions and high-priority defects**

**Photo Standards:**
- **Resolution**: Minimum 8MP, preferably 12MP+
- **Focus**: Sharp, clear images showing defect details
- **Lighting**: Adequate lighting, avoid shadows/glare
- **Scale**: Include measurement reference in photo
- **Angles**: Multiple angles for complex defects
- **Labeling**: Clear identification of defect type

**Required Photos:**
- Overview shot of entire weld
- Close-up of any defects
- Measurement verification shots
- Before/after remedial work
- Final acceptance photos

### **5.2 Notes Documentation**
**Detailed notes required for every inspection item**

**Note Requirements:**
- **Location**: Precise defect location
- **Dimensions**: Actual measurements
- **Severity**: Impact assessment
- **Recommendations**: Remedial actions
- **References**: Applicable code sections

**Note Examples:**
- "Undercut 3/64" deep x 1.5" long at 6 o'clock position, weld joint A-1"
- "Porosity cluster observed, 5 pores totaling 7/16" per inch, exceeds 3/8" limit"
- "No defects observed, weld meets AWS D1.1 Table 8.1 criteria"

## **9. EMERGENCY PROCEDURES**

### **9.1 Critical Defect Discovery**
**Immediate Actions for Cracks or Safety Issues:**
1. **STOP** - Halt all welding operations immediately
2. **NOTIFY** - Alert supervision and safety personnel
3. **DOCUMENT** - Photograph and measure defect
4. **SECURE** - Isolate affected area
5. **REPORT** - Generate immediate inspection report

### **9.2 System Failure During Inspection**
**If WeldTrack™ platform becomes unavailable:**
1. Continue inspection using backup methods
2. Document findings on paper forms
3. Take photos with backup device
4. Transfer data when system restored
5. Report system issues to support
